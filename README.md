Site Internet de mathieub.cv

# Installation

## Thème
- Clone le repo du thème `git clone https://github.com/mathieubti/portfolYOU.git`
`- cd portfolYOU`
- Remove following folders and files:
- - assets
- - _includes
- - _layouts
- - LICENSE 
- - portfolyou-jekyll-theme.gemspec
- - README.md
- - _sass
- - screenshot.gif
- - test
- Remove *_elements* documentation 
- move `mv docs/` .
- Remove docs folder

# Running

## Locally
`bundle exec jekyll serve --livereload`
